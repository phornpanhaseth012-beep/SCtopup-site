# SC Gaming Website Starter

A responsive static storefront template for Mobile Legends: Bang Bang and Free Fire.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — package selection, example totals, and order-message generator

## Preview on your phone
Open `index.html` in a browser, or publish the files using GitHub Pages / Netlify.

## Upload to your GitHub repository
1. Download and extract `SC-Gaming-Website.zip`.
2. Open your repository on GitHub.
3. Choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` (you can select multiple files).
5. Scroll down and tap **Commit changes**.

## Important before going live
- Package names and prices are examples. Update them in `script.js` and in the package buttons in `index.html`.
- Replace the support placeholder with your real official contact link.
- This is a front-end template only. It does not process KHQR payments, verify payments, deliver diamonds, or store orders on a server.
- Never ask customers for game passwords or one-time codes.
- Use only authorized top-up channels and follow each game's rules and publisher policies.
- Do not claim affiliation with Moonton or Garena.
